# Tiger-01 Synthesizer Engine
An open-source bare-metal hardware implementation of the Whetstone Games Offbeat sound matrix synthesizer engine.
### Current Progress (v0.1 Pre-Alpha)
* Fully compiled 3-Bank, 12-Instrument SoundFont architecture mapped across 3 octaves.
* Corrected asset loop playback behaviors and custom octave-switching boundaries.
* Integrated standalone PlatformIO core firmware scaffolding targeting ESP32-S3.
